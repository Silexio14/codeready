🧩 Extensions utiles dans VS Code

Ouvre l'onglet Extensions dans VS Code (icône des petits carrés), cherche le nom indiqué puis vérifie l'éditeur avant d'installer.

Python — MicrosoftExécuter des fichiers Python, choisir l'interpréteur et utiliser les outils Python.Voir l'extension ↗
Pylance — MicrosoftSuggestions, complétion de code et aide pour repérer certaines erreurs.Voir l'extension ↗
Python Debugger — MicrosoftMettre le programme en pause et examiner les valeurs pour comprendre un bug.Voir l'extension ↗
Jupyter — Microsoft (facultatif)Créer des notebooks avec du code et des explications dans des cellules.Voir l'extension ↗

Commence avec Python et Pylance. Les autres extensions sont facultatives : installe-les seulement quand une leçon en a besoin.

⌨️ Installer les bibliothèques Turtle et Pygame

Turtle est généralement inclus avec Python sur les installations classiques. Pygame doit être ajouté dans le terminal de l'environnement Python utilisé par ton projet.

python -m pip install pygame

Si la commande ne fonctionne pas, vérifie d'abord que Python est installé et que VS Code utilise le bon interpréteur. Ne copie pas des commandes provenant de sites inconnus.
